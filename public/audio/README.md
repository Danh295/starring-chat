# Drop-in audio

Put your own audio here. With no files, the overlay plays a short synthesized sting and a synthesized theme, so nothing is required.

| File | Played when | Notes |
| --- | --- | --- |
| `sting.mp3` | A role card is revealed (volume 40%) | About 3 seconds |
| `theme.mp3` | The end credits roll (volume 40%) | About 45 seconds; it is cut off when the credits end |

In OBS, tick "Control audio via OBS" on the browser source so the sound goes through your mixer.
Only use music you made or have the rights to use (a copyright claim on a stream or video is not worth it).
