Turn your chat into a cast

Every new chatter gets a role on stream, like a character in a sitcom. Setup takes about two minutes and there is nothing to download.

  1. 1

    Your channel

    Type the name of your Twitch channel.

  2. 2

    Add it to OBS

    Copy your overlay link, then add it as a Browser source.

    Width 1920Height 1080Tick Control audio via OBS

    In OBS, under Sources select +, choose Browser, paste the link, set those three things, and select OK. Streamlabs works the same way.

  3. 3

    See it work

    Send yourself a test card to check the overlay is showing.

  4. 4

    Tell your chat

    Paste this into chat once so viewers know what the cards are. It has no links, so link filters leave it alone.

Chat commands
!lurk
Anyone: join as a Background Extra.
!nocast
Anyone: opt out. Their card is removed and they are never cast again.
!credits
You or a mod: roll the end credits (about 45 seconds).
!newepisode
You or a mod: start a fresh episode with a clean cast.
!uncast @name
You or a mod: remove someone from tonight's cast.
Something is not working
The test card did not appear in OBS
Check the link is pasted exactly, the Browser source is visible in your scene, and the channel name is spelled like your Twitch name.
Cards show but there is no sound
Tick Control audio via OBS on the Browser source, then check it is not muted in the audio mixer.
Viewers are not getting cards
The server must be running and connected to your chat. Open the control room to see whether casting is on.
I want to turn it off
Hide or delete the Browser source, or pause casting in the control room.
